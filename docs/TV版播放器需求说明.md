# ZL-Music TV 版播放器 · 功能需求说明

> 版本基线：v1.9.21（Android TV，armeabi-v7a 构建）
> 适用设备：Android TV / 电视盒子（仅 TV 形态，`isTV` 判定后启用 TV 专属交互）
> 形态：单原生 Screen 承载 6 个顶部 Tab，播放页 / 详情页 / 下载面板 / 重命名页以子屏（push）叠加

---

## 1. 产品概述

- 面向大屏遥控器交互的音乐播放器，**无后端服务器**，直接使用各音源数据在线播放。
- 核心目标：在电视上用遥控器完成「发现音乐 → 播放 → 管理音源/歌单 → 下载」全流程。
- 设计语言参考 Apple Music TV：专辑主色动态背景、黑胶/海报转场、tvOS 风格焦点（裸图标→聚焦变白底反色）。

---

## 2. 整体架构与导航

- **TV Shell（外壳）**：6 个 Tab 共用一个原生 Screen，首屏只挂「推荐」，其余 Tab 在启动后空闲时串行预挂载（避免同时建树卡顿）。切 Tab 只改透明度、不重建页面。
- **顶部 Tab（顺序固定）**：推荐 / 排行榜 / 播放列表 / 我的歌单 / 搜索 / 设置。焦点移到 Tab 即自动切换（无需按 OK），统一走「回首页再 push」避免返回栈堆叠。
- **子屏（push 叠加在最上层）**：
  - 播放页（`pushTVPlayerScreen`）
  - 歌单 / 榜单详情（`pushTVDetailScreen`）
  - 下载管理面板（`TVDownloadPanel`）
  - 歌单重命名（`pushTVRenameScreen`）
- **焦点管理**：自研 `tvFocusManager`，Tab 切换 / 子屏开关时通过焦点作用域（scope）接管遥控器，避免背景页误吞按键。
- **返回规则**：首页返回键先弹「退出应用」确认框；其余 Tab 返回切回首页；子屏返回关闭自身（下载面板多选态下返回先退出多选）。

---

## 3. 遥控器交互规范

### 3.1 全局通用键位

| 按键 | 行为 |
|---|---|
| 上 / 下 / 左 / 右 | 焦点移动（列表 / 卡片 / 按钮之间） |
| OK（select） | 激活当前焦点项（播放歌曲、打开歌单、确认按钮）；长按 OK 触发管理菜单（删除 / 测试网络等） |
| 返回（back） | 子屏关闭 / Tab 回首页 / 首页弹退出确认 |
| 菜单（menu） | 播放页：呼出控制栏 |
| 遥控器「播放/暂停」媒体键 | 播放页：播放/暂停；首页：播放或跳转搜索 |

### 3.2 播放页专用键位（对齐 Apple Music TV）

控制栏分两种状态：

- **听歌模式（控制栏隐藏）**：
  - OK = 播放/暂停
  - 左 / 右 短按 = 上一首 / 下一首
  - 长按左/右 = 仅记账、松手不切歌（快进/快退功能已移除）
  - 上 / 下 / 菜单 = 呼出控制栏并聚焦播放键
- **操作模式（控制栏显示）**：方向键只做焦点导航，切歌需焦点移到按钮按 OK 确认。
- **进度条聚焦时**：左/右 改为拖动进度（短按 ±5s，长按重复 ±1s，松手/离开补提交落位），不再切歌。
- **歌词区长按 OK**：进入全屏歌词；OK / 返回退出。

## 4. 模块功能详述

### 4.1 首页（推荐）
- Hero 大图 + 歌单货架（以实测屏高等比缩放，保证一屏放下、无需下滑）。
- 顶部常驻：播放/暂停、上一首/下一首（有歌曲时直接控制播放器并跳播放页）、搜索入口。
- 展示推荐歌单（取当前榜单源的前 12 个），OK 打开歌单详情。
- 首页返回键弹「退出应用」确认框，防误触退出。

### 4.2 排行榜
- 展示平台热门歌曲 / 榜单排行（榜单源跟随排行榜页选择，持久化键 `tv_board_source`，未选回退酷我）。
- 榜单预览：OK 查看榜单歌曲；打开后获取该榜真实歌曲列表，可播放全部或单选。

### 4.3 播放列表（播放列表 Tab）
- 展示当前播放队列（「接下来」/ 全部），真实音乐列表来源。
- 支持：立即播放某首、清空列表、单曲从队列移除（长按 / 详情操作）。
- 空态提示：先从榜单或搜索获取音乐。

### 4.4 我的歌单
- 展示用户自建歌单（含手机导入、本地歌单），不含「试听列表 / 我的收藏」重复项。
- 每张卡片带**封面（首歌专辑图）与歌曲数**（加歌后实时更新）。
- 常驻「导入歌单」入口卡（空态时兼任提示）。
- 长按 OK：管理歌单（改名 / 删除）。改名受限于电视输入（见 4.10）。
- 本地磁盘导入：从磁盘文件夹添加本地歌（需存储权限）。
- 手机扫码导入的歌单结果缓存，回到本页仍可见。

### 4.5 搜索
- 电视端屏上输入：屏上键盘（`TVSearchKeyboard`）+ 系统输入法 `TextInput`（OK 拉起 IME）。
- 热搜词快捷选择（周杰伦/林俊杰/陈奕迅等）。
- **搜索历史**：持久化（项目自带 storage 插件），长按单条删除、一键清空。
- 音源选择 Tab（全部 / 各平台源），结果分页「加载更多」。
- 结果列表：OK 立即播放并跳播放页；「播放全部」整列入队。

### 4.6 设置
- **音源列表**（左栏，最常用的内容）：
  - 类型：聚合音源 / 预设用户 API / 内置直连源 / 第三方用户 API。
  - OK = 选用该音源（在线播放通常需可用的用户 API）。
  - 长按 OK = 管理菜单：**测试网络**、删除音源、开关更新提醒。
  - 列表提示：「OK 键使用音源 · 长按 OK 键可测试网络/删除/管理」。
- **添加第三方音源**（右栏）：
  - `TextInput` 输入框，OK 拉起系统输入法，输入 `https://...js` 脚本网址或粘贴整段脚本。
  - 「导入」：网址自动抓取脚本 → 校验导入 → 导入后**自动测一次网络**并弹窗告知可用/不可用。
- **测试音源**（音源诊断）：
  - 按「测试音源」按钮，依次加载每个已配置源（当前使用 + 已添加的第三方 + 预设 + 内置）测连通性。
  - 弹窗逐条显示：`✓ 正常` / `✗ 失败原因` / `· 内置直连（TV 端不单独测）`。失败原因截断首行、去堆栈。
- **检查更新**（GitHub Release）：检查 → 下载 APK → 打开系统安装器安装（含进度、版本信息）。
- **手机扫码导入**：启动局域网服务，手机扫码打开页面，可导入音源/歌单，也能给歌单改名、删除（推送歌单快照到手机）。
- **退出应用**确认。

### 4.7 播放页
- 大封面（加载中转黑胶唱片，onLoad 后淡入海报）、专辑主色动态背景。
- 控制栏（默认常驻，可开关为 5s 后自动隐藏）：播放模式切换、上一首/下一首、播放/暂停、下载、常驻开关。
- 进度条 seek（聚焦后左右拖动，节流提交）。
- 歌词：当前行高亮 + 译文；歌词区长按 OK 进全屏歌词；无歌词/加载中占位处理。
- 单曲下载入口：按音质（24bit/无损/320k/128k）选择后入下载队列。
- 本地歌曲不显示下载按钮、标记「本地」徽标。

### 4.8 歌单 / 榜单详情
- 展示歌单/榜单内真实歌曲列表。
- OK = 播放整张歌单；长按 OK = 追加到播放列表 / 删除这首歌。
- 队列来源标注。

### 4.9 下载管理（TVDownloadPanel）
- 全屏覆盖层（返回键关闭；多选态返回先退出多选）。
- 任务行 OK 弹出操作菜单：暂停 / 继续 / 删除。
- 多选模式：勾选后批量删除。
- 底部：多选开关、清空已完成、清空失败、修改保存位置（选择文件夹）、恢复默认。
- 任务进度/速度/状态实时显示（下载中/等待/已暂停/失败/已完成）。

### 4.10 歌单重命名
- 电视屏上改名（屏上键盘，仅英文/数字，中文名请在手机扫码页改）。
- 保存到本地。

## 5. 音源体系

TV 版所有可播放内容都来自「音源」。设置页左侧 `allSources` 列表即全部已配置音源，展示顺序为：**第三方用户 API → 聚合音源 → TV 预设用户 API → 内置直连源**。

### 5.1 音源分类与具体清单（含内部 ID）

| 类型 | 显示名 | 内部 ID | 是否 TV 专属 | 说明 |
|---|---|---|---|---|
| 第三方用户 API | 导入时命名（如「星海音乐源」） | 导入时生成 | 否 | 用户通过「添加第三方音源」或手机扫码导入的 `.js` 脚本，可带版本号 |
| 聚合音源（内置） | 聚合音源 | 空串 `''` | 是 | 综合所有可用人源，无需脚本 |
| TV 预设用户 API | 聚合API接口 (CF) | `tv_preset_juhe` | 是 | 作者 lerd，内置打包；UI 显示为「聚合音源」 |
| TV 预设用户 API | 野草 | `tv_preset_grass` | 是 | 作者 pdone，内置打包 |
| 内置直连源 | 酷我 | `kw` | 否 | 直连平台 |
| 内置直连源 | 酷狗 | `kg` | 否 | 直连平台 |
| 内置直连源 | QQ音乐 | `tx` | 否 | 直连平台 |
| 内置直连源 | 网易云 | `wy` | 否 | 直连平台 |
| 内置直连源 | 咪咕 | `mg` | 否 | 直连平台 |
| 内置直连源 | 本地 | `local` | 否 | 本地磁盘导入的音乐 |

> 注：`getSourceName` 中还保留了 `tv_preset_huibq`（Huibq·音源）、`tv_preset_flower`（Flower·音源）的名称兜底，但**它们并未作为预设打包进 TV 版**，仅用于兼容外部导入的同 ID 音源显示名。TV 版实际内置的预设只有 `tv_preset_juhe` 与 `tv_preset_grass` 两个。
> TV 专属音源（聚合、`tv_preset_juhe`、`tv_preset_grass`）的脚本由 App 内置打包，用户不可改脚本内容，只能「选用 / 从列表隐藏（移除）/ 测网络 / 开关更新提醒」。内置直连源来自 `apiSourceInfo`，可在设置中「移除」（仅从 TV 列表隐藏）。

### 5.2 命名重叠说明
「聚合音源」会**出现两次**：一个是内置聚合源（id 为空串，标记为「内置直连」、TV 端不单独测网络），另一个是 `tv_preset_juhe` 预设（UI 同样显示为「聚合音源」）。诊断 / 选用时需注意区分。

### 5.3 音源诊断（测试音源）
设置页「测试音源」按钮依次加载每个已配置音源检测连通性，结果弹窗示例（电视实测）：
```
✓ 星海音乐源（正常）
· 聚合音源（内置直连）
✗ 聚合音源（脚本初始化失败）
✗ 野草（服务器异常）
```
- 内置直连 / 聚合源：标注「内置直连」，**不单独发请求测网络**（需真实搜索才能验证）。
- 用户 API / 预设：加载该源 → 监听初始化结果，超时（10s）兜底判失败；失败原因截断首行、去除 `UnhandledPromiseRejectionException:` 前缀、限长 60 字符，避免整段 JS 堆栈撑爆弹窗。

### 5.4 启动音源选择逻辑（已修复）
- 启动时若 `common.apiSource` 已是用户的选择（内置 / 第三方 / 预设），直接加载它，**不再强制切回首个预设**。
- 仅当该源未设置、被移除、或加载失败时，才回退到内置预设；且回退不写回、不覆盖用户已保存选择。

## 6. 本地音乐
- 从磁盘文件夹导入本地歌（存储权限请求）。
- 本地歌曲标记「本地」徽标，无下载概念（播放页不显示下载按钮）。
- 本地歌歌词需在线多源匹配，慢时按「暂无歌词」先显示再自动覆盖。

---

## 7. 播放与歌词
- 播放模式：随机 / 列表循环 / 单曲循环 / 顺序 / 播完停止。
- 切歌过渡处理：切歌期间维持「播放中」图标，避免闪「已暂停」。
- 歌词：逐行高亮、译文、全屏歌词模式；过滤作词/作曲/版权/推广等元信息行。

---

## 8. 非功能性需求

- **焦点管理**：自研焦点框架 + 作用域，Tab 切换 / 子屏开关正确接管遥控器；列表「聚焦即滚动」保证焦点项可见。
- **性能**：固定行高 + `getItemLayout` 让长下载列表滚动不卡；方向键事件全在 JS 线程分发，避免逐帧重渲染死循环。
- **局域网导入**：原生局域网服务单例，Settings 实例持有会话归属 token，避免重复导入。
- **应用更新**：从 GitHub Release 检查/下载/安装，适配 Android 10 手动确认。
- **弹窗**：全局 `TVDialog` 注册表 + 当前屏宿主，深层屏返回后弹窗不静默失效。

---

## 9. 已知限制 / 待确认
- 电视屏上键盘仅支持英文/数字，**中文歌单名 / 中文输入需在手机扫码页完成**。
- 内置直连源在 TV 端不单独发请求测网络（需真实搜索才能验证直连），诊断中标注「内置直连」。
- 测试网络单源超时约 10s，全部源依次测试，源较多时整体耗时较长。
- 第三方用户 API 初始化失败会回退到内置预设让播放可用，但**不覆盖**用户已保存的音源选择。
